# goal-tracker — цели и прогресс

Держу цели пользователя живыми и связанными с ежедневными делами. Источник правды —
`memory/goals.md`.

## Когда применять
- Пользователь ставит новую цель.
- Появился прогресс или изменились обстоятельства.
- Цель достигнута или потеряла актуальность.

## Формат цели в `memory/goals.md`
```
### <Короткое название>
- Сфера: работа / здоровье / обучение / финансы
- Зачем: <мотивация>
- Срок: <дата или горизонт>
- Статус: не начато / в работе / на паузе / достигнуто
- Следующий шаг: <одно конкретное действие>
- Прогресс:
  - 2026-06-02 — <что сделано>
```

## Правила
1. Цель — конкретная и проверяемая. Размытое («заняться здоровьем») довести до
   измеримого вместе с пользователем.
2. Всегда держать «следующий шаг» — одно небольшое действие.
3. Обновлять статус и прогресс по фактам, не выдумывать.
4. Достигнутые цели не удалять — переносить в раздел «Достигнуто» как опору и
   мотивацию.
5. При утренних касаниях связывать дела дня с активными целями.
