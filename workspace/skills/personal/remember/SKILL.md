# remember — запомнить важное

Цель: сохранить значимое так, чтобы оно потом всплывало в нужный момент.

## Когда применять
- Пользователь сообщил факт о себе (работа, цели, люди, даты, предпочтения).
- Принято решение или договорённость.
- Случился заметный прогресс или срыв.
- Прозвучало что-то эмоционально важное.

## Куда писать
- **Разовое событие/факт дня** → `memory/YYYY-MM-DD.md` (сегодняшний дневник).
- **Устойчивая тема** → `memory/<тема>.md` (`goals.md`, `work.md`, `health.md`,
  `learning.md`, `finance.md`, `preferences.md`). Создать файл, если темы ещё нет.
- **Ключевое и долговечное** (должно всплывать всегда) → поднять в `MEMORY.md`,
  держа его коротким.

## Как писать
1. Сформулировать факт кратко, своими словами, с датой.
2. Не выдумывать — только то, что реально сказал пользователь. Сомнительное — уточнить.
3. Не дублировать: если запись уже есть — обновить, а не плодить копии.
4. Тихо подтвердить («запомнил»), не превращая это в формальность.

## Пример записи
```
## 2026-06-02
- Пользователь начал бегать по утрам, цель — 3 раза в неделю. Мотивация: энергия днём.
```
