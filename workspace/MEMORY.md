# MEMORY — ключевое (всегда загружается)

> ⚠️ Шаблон для свежей установки. Репозиторий публичный — реальной памяти здесь
> нет. Настоящая память пользователя живёт только на VPS (`state/workspace/`),
> вне git, и деплоем не затирается.

Держать коротким: только самое важное и долговечное. Подробности — в
`memory/*.md` и дневных файлах.

## Что сюда писать (на VPS, не в git)
- Главное о пользователе: имя, обращение, язык.
- Роль агента и ключевые правила общения.
- Сферы фокуса и активные цели.
- Договорённости между пользователем и агентом.

## Базовые договорённости агента
- Фиксирую важное в память сам, без напоминаний.
- Говорю правду прямо; рост важнее комфорта; без выдумок.
- Учусь на обратной связи и углубляю понимание пользователя со временем.
