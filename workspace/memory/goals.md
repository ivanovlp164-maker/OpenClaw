# Цели — шаблон

> Живой файл памяти. Реальные цели пользователя живут на VPS, вне git.
> Формат каждой цели: что, зачем, срок, статус, следующий шаг.

```
### <Короткое название цели>
- Сфера: <работа / здоровье / обучение / финансы / ...>
- Зачем: <мотивация>
- Срок: <дата или горизонт>
- Статус: не начато / в работе / на паузе / достигнуто
- Следующий шаг: <одно конкретное действие>
- Прогресс:
  - YYYY-MM-DD — <что сделано>
```

*Заполняется в разговоре. Не выдумывать — только со слов пользователя.*
