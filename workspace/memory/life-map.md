# Карта жизни — шаблон

> Живой файл памяти. Реальная карта жизни пользователя живёт на VPS, вне git.
> Агент заполняет и обновляет её по мере общения. Не выдумывать — только факты.

## Как читать карту
Каждая сфера: **где сейчас → куда хочу → что мешает → первый шаг**.
Цели с трекингом — в `goals.md`. Динамика дня — в дневных файлах.

## Сферы (пример набора, адаптировать под пользователя)
- 🧭 Ядро: ценности, видение на 3–5 лет, главный вызов.
- 💼 Работа / реализация
- 🏃 Здоровье / привычки
- 📚 Обучение / навыки
- 💰 Финансы / цели
- 👥 Близкие и связи
- 😌 Эмоциональный фон
- 🌍 Окружение / среда

## Метод
1. Раз в период — самооценка по сферам (1–10), искать «узор»: где провисает.
2. По каждой сфере: 1 победа, 1 затык, 1 следующий шаг.
3. Связывать ежедневные дела с целями. Рост важнее комфорта.
