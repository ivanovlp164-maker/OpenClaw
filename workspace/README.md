# workspace/ — личность, память и навыки агента

Git-управляемый **обезличенный baseline** персонального агента (Кло). На VPS
синхронизируется в живой workspace OpenClaw (`state/workspace` →
`/home/node/.openclaw/workspace`) скриптом `scripts/sync-workspace.sh`,
который вызывается при каждом деплое (`scripts/update.sh`).

> ⚠️ **Репозиторий публичный.** Поэтому здесь нет реальных персональных данных.
> Настоящий профиль, тонкая настройка персоны и память конкретного пользователя
> живут **только на VPS** (`state/workspace/`, в `.gitignore`) — приватно.

## Что где

| Файл / папка     | Назначение                                    | При деплое |
| ---------------- | --------------------------------------------- | ---------- |
| `skills/`        | Навыки (`<группа>/<навык>/SKILL.md`)           | перезапись |
| `IDENTITY.md`    | Имя, образ, роль агента (baseline)            | сид*       |
| `SOUL.md`        | Личность, тон, границы (baseline)             | сид*       |
| `USER.md`        | Шаблон профиля (реальный — на VPS)            | сид*       |
| `AGENTS.md`      | Операционка: память, правила, поведение       | сид*       |
| `HEARTBEAT.md`   | Ритм проактивности (формат CEO-пуша)          | сид*       |
| `MEMORY.md`      | Шаблон ключевой памяти                         | сид*       |
| `memory/*.md`    | Шаблоны памяти (реальная — на VPS)            | сид*       |

\* **сид** = копируется только если файла ещё нет на VPS. Живой настроенный
конфиг и накопленная память **никогда не затираются** деплоем.

## Почему так

- **Навыки** обновляются из git — это переиспользуемая возможность, не личные
  данные. Безопасно перезаписывать.
- **Персона, профиль и память** настраиваются под пользователя на VPS и часто
  чувствительны. Git держит лишь baseline для свежей установки и не трогает
  живой setup.

## Навыки в комплекте
- `remember` — зафиксировать важное в память.
- `daily-reflection` — утренний план и вечерний разбор (формат CEO-пуша).
- `weekly-review` — недельный обзор по сферам жизни.
- `goal-tracker` — вести цели и прогресс.
- `understand-me` — глубже понять пользователя: разбор истории и памяти.

## Как править с телефона
1. Working Copy → файл в `workspace/` (навык или baseline).
2. Коммит + пуш в ветку, PR, мердж в `main` → `deploy` синхронизирует навыки.
3. Персональную настройку правь прямо в агенте (он сам пишет память на VPS),
   а не в git.
