# 🌊 Подводный футбол

3D-игра для браузера (телефон и компьютер): футбол 5 на 5 под водой, с вратарями.

## Как играть

- Открой `index.html` через любой статический сервер (например, `python3 -m http.server`)
  или собери однофайловую версию: `./build-artifact.sh` → `dist/underwater-football.html`.
- **Телефон (горизонтально)**: левая половина экрана — джойстик движения;
  правый джойстик-«мяч» — всплыть/нырять и поворот камеры; кнопки ПАС / УДАР / НАВЕС
  (удерживай — заряжается сила, видна белая дуга прицела); ⚡ — спринт.
- **Компьютер**: WASD — плыть, Space/C — вверх/вниз, Q/E — камера, Shift — спринт,
  J — пас, K — удар, L — навес (удерживай для силы).

## Правила

- 5 на 5 с вратарями, два тайма по 44 «игровые» минуты (~3,5 реальных).
- Перед матчем выбирается уровень соперника (лёгкий/средний/сложный) и
  стратегия команды (агрессивная/умеренная/защитная).
- Вода трёхмерная: движение вперёд/назад, влево/вправо, вверх/вниз.
- У каждого игрока есть запас **воздуха**. Мало воздуха — всплываешь с ускорением.
  Совсем кончился — игрок отключается, за ним ныряют **медики**, поднимают наверх,
  пару секунд откачивают и возвращают в игру.
- Боты сами следят, чтобы кто-то из команды всегда дежурил наверху, и меняются.
- Спринт ⚡ тратит энергию; она восстанавливается медленнее при усталости и нехватке воздуха.
- Когда мяч не виден, у края экрана появляется стрелка-указатель на него.
- Голы и победы приносят **монеты** 🪙. В магазине за монеты прокачивается
  **дыхание всей команды** (+25% запаса воздуха за уровень). Прогресс сохраняется.

## Технически

- Three.js r128 (лежит в `vendor/`), один файл логики `game.js`, без сборщиков.
- `build-artifact.sh` склеивает всё в один HTML-файл для публикации.
